# Code repository for "Story in the Numbers" 

This is the repository of the code I wrote for my "Story in the Numbers" Substack post. 

The `scripts/` subfolder has my code. The 'dol' scripts are for the Department of Labor data, and the 'open_doors' scripts are for the Open Doors (IIE) data. 

The actual data files are not posted here because the files are large. Refer to the URLs below for publicly downloadable data. 

While this repository is structured like an R package, it is not intended to be published as a software package. The structure is for organizational purposes only. 

Friendly reminder: Writing is something I do outside of my full time work. All ideas and work here are my own opinions, with no connection to my current employer. 

## Data Availability 

(1) The Department of Labor data referenced here comes from the official DOL site: 
https://www.dol.gov/agencies/eta/foreign-labor/performance

Refer to the LCA data from 2021-2025 (all quarters).  

(2) The IIE data referenced here comes from the official IIE Open Doors site: 
https://opendoorsdata.org/annual-release/international-students/#download-data
